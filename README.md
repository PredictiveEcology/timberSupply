Timber supply on LandR landscapes: the questions a Timber Supply Review asks.
Where can harvest happen (timber harvesting land base, harvest constraints)?
How long between cuts (rotation age)? How much (annual allowable cut)?
What is cut, and what does it yield (merchantable oven-dry tonnes)?

# install.packages("remotes")
remotes::install_github("PredictiveEcology/timberSupply@development")
